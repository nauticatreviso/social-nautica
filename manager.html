📁 Google Drive (opzionale)

Per sfogliare Google Drive dal Manager:
1. Vai su Google Cloud Console
2. Crea un progetto (o usane uno esistente)
3. Abilita Google Drive API e Google Picker API
4. Crea credenziali: OAuth 2.0 Client ID (tipo "Web") → aggiungi l'URL di questa pagina come "Origini JavaScript autorizzate"
5. Crea una API Key (limitala a Picker API)
6. Incolla qui sopra Client ID e API Key
